# Telegram-бот «Командный планировщик»

Учебный MVP Telegram-бота для групповых чатов. Бот хранит общий список задач, назначает ответственных, напоминает о дедлайнах, считает недельную статистику, суммаризирует последние сообщения через Gemini и создаёт голосования.

## Возможности

- `/addtask Текст | @username | 2026-08-15 18:00` — добавить задачу.
- `/tasks` — показать открытые задачи группы.
- `/done ID` — отметить задачу выполненной.
- `/stats` — статистика выполненных задач за последние 7 дней.
- `/summarize` — краткое AI-резюме последних 20 сообщений, которые видел бот.
- `/poll Когда созвон? Понедельник, Среда, Пятница` — быстрое голосование.
- Естественный язык: например `Добавь задачу @anna подготовить отчёт к пятнице 18:00`.
- Автоматическое напоминание примерно за сутки до дедлайна.

## Стек

- Python 3.12+
- aiogram 3
- SQLite + aiosqlite
- Google Gemini API через `google-genai`
- Long polling

## 1. Создание Telegram-бота

1. Откройте `@BotFather` в Telegram.
2. Выполните `/newbot` и получите токен.
3. Для работы суммаризации в группе выполните `/setprivacy` → выберите бота → `Disable`.
4. Добавьте бота в нужную Telegram-группу.

Важно: после отключения Privacy Mode удалите бота из группы и добавьте заново, если Telegram не начал передавать обычные сообщения сразу.

## 2. Gemini API

Получите Gemini API key в Google AI Studio и сохраните его только в `.env`. Не публикуйте `.env` в GitHub.

## 3. Установка на Windows 11

Откройте папку проекта в Cursor. В терминале выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и вставьте значения:

```env
BOT_TOKEN=ваш_telegram_token
GEMINI_API_KEY=ваш_gemini_api_key
GEMINI_MODEL=gemini-3.5-flash
```

Запуск:

```powershell
python bot.py
```

При успешном запуске терминал остаётся открытым и бот начинает отвечать в Telegram.

## Проверка критериев

### 1. Работа в группе

Добавьте бота в тестовую группу и отправьте `/start`, `/tasks`.

### 2. Задачи и ответственный

```text
/addtask Подготовить презентацию | @anna | 2026-08-15 18:00
```

Затем:

```text
/tasks
```

### 3. Статистика

Отметьте задачу выполненной:

```text
/done 1
```

После этого:

```text
/stats
```

### 4. AI-суммаризация

Напишите в группе несколько обычных сообщений, затем:

```text
/summarize
```

### 5. Голосование

```text
/poll Когда созвон? Понедельник, Среда, Пятница
```

### 6. Естественный язык

```text
Добавь задачу @anna подготовить коммерческое предложение к пятнице 18:00
```

Gemini извлечёт название задачи, ответственного и дедлайн.

## Важное техническое замечание про Telegram username

Telegram Bot API не предоставляет произвольный поиск пользователя по `@username`. Поэтому бот ведёт локальный реестр участников, которых уже видел в группе: сохраняет их `Telegram user_id` и `@username`. Если назначаемый участник хотя бы один раз написал сообщение после добавления бота, задача получает и его точный `user_id`, и `@username`. Статистика группируется по назначенному ответственному.
